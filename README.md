# 長野 林道カルテマップ

長野県の「名前のついた林道」を列挙し、通行状況・冬季閉鎖などのカルテを地図上に表示するWebアプリA（単一HTML）。

**公開URL**: GitHub Pages 有効化後にここに記載（例: `https://<ユーザー名>.github.io/rindo-nagano-map/`）

## 使い方

`index.html` を開くだけ（ビルド不要）。スマホ表示に最適化。

- **緑ピン（カルテ）**: 通行規制・冬季閉鎖・出典を調査済みの林道。タップで詳細シート。
- **金ドット（Lv1候補）**: 行政資料×OSMでクロス確認済みの肉付け対象。
- **青ドット（Lv0）**: OSM由来の骨格。名前と概略位置のみ。
- 「この範囲の林道を取得（OSM）」ボタン: 表示範囲のOSM林道ラインをその場で取得（路面判定つき）。

### 便利機能

- 🔍 **検索・絞り込み**（バーの🔍）: 林道名で検索して飛ぶ。市町村・通行可否・冬季閉鎖でカルテを絞り込み。
- 📴 **オフライン対応（PWA）**: 一度表示した地図範囲は電波が無くても再表示。スマホの「ホーム画面に追加」でアプリのように起動。
- 🔗 **共有リンク**: カルテの「🔗 共有」で `?id=...` 付きURLをコピー。開くとそのカルテが直接開く。

## データの構成（レベル）

- **Lv0**: 存在確認された林道の列挙（名称＋概略座標、OSM＋行政資料）。長野県で945件。
- **Lv1**: 市町村・座標を確定した肉付け候補。
- **Lv2（カルテ）**: 通行規制・冬季閉鎖などを出典付きで調査。38件。
